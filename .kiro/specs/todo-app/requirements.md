# TODO管理Webアプリ 要件定義

## 概要

Pythonを使ったマルチユーザー対応のTODO管理Webアプリケーション。
FlaskフレームワークとSQLiteデータベースを使用し、Bootstrap 5でモダンなUIを実現する。
繰り返しタスク・完成度・ユーザー認証・プロジェクト階層管理・進捗予測に対応する。

---

## ユーザーストーリー

### 1. 認証

- **US-00-1**: ユーザーとして、アカウントを新規登録したい
- **US-00-2**: ユーザーとして、メールアドレスとパスワードでログインしたい
- **US-00-3**: ユーザーとして、ログアウトしたい
- **US-00-4**: ユーザーとして、自分のTODOだけが見えるようにしたい

### 2. TODO基本操作

- **US-01**: ユーザーとして、新しいTODOをタイトルと共に追加したい
- **US-02**: ユーザーとして、登録済みTODOの一覧を確認したい
- **US-03**: ユーザーとして、TODOのタイトルや詳細を編集したい
- **US-04**: ユーザーとして、TODOを完了/未完了に切り替えたい
- **US-05**: ユーザーとして、不要になったTODOを削除したい

### 3. 詳細情報の設定

- **US-06**: ユーザーとして、TODOに締め切り日を設定したい（期限切れは視覚的に強調表示）
- **US-07**: ユーザーとして、TODOに優先度（高/中/低）を設定したい
- **US-08**: ユーザーとして、TODOにカテゴリ（タグ）を割り当てたい
- **US-09**: ユーザーとして、カテゴリを自由に作成・編集・削除したい

### 4. 完成度

- **US-10**: ユーザーとして、TODOに完成度（0〜100%）を設定したい
- **US-11**: ユーザーとして、完成度がプログレスバーで視覚的に確認できるようにしたい
- **US-12**: ユーザーとして、完成度に応じてバーの色が濃くなり、100%で最も濃い色になるようにしたい
- **US-13**: ユーザーとして、完成度の数値（例: 75%）がバー上に表示されるようにしたい

### 5. 繰り返しタスク

- **US-14**: ユーザーとして、TODOに繰り返しパターン（毎日・毎週・毎月）を設定したい
- **US-15**: ユーザーとして、繰り返しの終了条件を「終了日」または「回数」で指定したい
- **US-16**: ユーザーとして、「今月分を生成」ボタンで繰り返しタスクを一括生成したい
- **US-17**: ユーザーとして、繰り返しタスクを編集するとき「この1件のみ」か「以降すべて」かを選べるようにしたい
- **US-18**: ユーザーとして、繰り返しタスクのグループを一覧で確認したい

### 6. プロジェクト・階層管理

- **US-24**: ユーザーとして、プロジェクト（例: TOEIC 850点取得）を作成したい
- **US-25**: ユーザーとして、プロジェクトに目標値・期限日を設定したい
- **US-26**: ユーザーとして、プロジェクト配下にサブタスクを階層的に追加したい（3階層以上対応）
- **US-27**: ユーザーとして、サブタスクに「完成度平均」か「数値目標に対する実績」のどちらで進捗を計算するか選びたい
- **US-28**: ユーザーとして、プロジェクト全体の進捗をプログレスバーで確認したい（サブタスクの進捗の平均）
- **US-29**: ユーザーとして、現在のペースから完了予測日を自動計算してほしい
- **US-30**: ユーザーとして、予定期限に対して遅延が見込まれる場合、プログレスバーにオーバー分を色違いで表示してほしい
- **US-31**: ユーザーとして、すでに期限を超過している場合は超過日数をバーに赤色で表示してほしい

### 7. 検索・フィルター

- **US-19**: ユーザーとして、キーワードでTODOを検索したい
- **US-20**: ユーザーとして、完了/未完了でフィルタリングしたい
- **US-21**: ユーザーとして、優先度でフィルタリングしたい
- **US-22**: ユーザーとして、カテゴリでフィルタリングしたい
- **US-23**: ユーザーとして、締め切り日でソートしたい

## 機能要件

### FR-00: ユーザー認証
| ID | 要件 |
|----|------|
| FR-00-1 | メールアドレスとパスワードでユーザー登録できること |
| FR-00-2 | ログイン・ログアウト機能があること |
| FR-00-3 | パスワードはハッシュ化して保存すること（Werkzeug使用） |
| FR-00-4 | 未ログイン時はログイン画面にリダイレクトされること |
| FR-00-5 | 各ユーザーは自分のTODO・カテゴリのみ閲覧・操作できること |

### FR-01: TODO管理
| ID | 要件 |
|----|------|
| FR-01-1 | タイトル（必須）、説明（任意）でTODOを作成できること |
| FR-01-2 | 作成済みTODOのタイトル・説明・締め切り日・優先度・カテゴリを編集できること |
| FR-01-3 | TODOを完了状態に切り替えられること（完了済みは一覧で視覚的に区別） |
| FR-01-4 | TODOを削除できること（確認ダイアログあり） |

### FR-02: 締め切り日
| ID | 要件 |
|----|------|
| FR-02-1 | TODOに任意で締め切り日（日付）を設定できること |
| FR-02-2 | 締め切りを過ぎたTODOは赤色で強調表示されること |
| FR-02-3 | 本日が締め切りのTODOは黄色で強調表示されること |

### FR-03: 優先度
| ID | 要件 |
|----|------|
| FR-03-1 | 優先度は「高・中・低」の3段階から選択できること |
| FR-03-2 | 優先度はバッジ（色付きラベル）で一覧上に表示されること（高=赤、中=橙、低=緑） |
| FR-03-3 | デフォルト優先度は「中」とすること |

### FR-04: カテゴリ管理
| ID | 要件 |
|----|------|
| FR-04-1 | カテゴリを自由に作成・編集・削除できること |
| FR-04-2 | 各TODOに1つのカテゴリを割り当てられること（任意） |
| FR-04-3 | カテゴリは色付きバッジで表示されること |
| FR-04-4 | カテゴリを削除した場合、紐付くTODOのカテゴリはNullになること |
| FR-04-5 | カテゴリはユーザーごとに独立して管理されること |

### FR-05: 完成度
| ID | 要件 |
|----|------|
| FR-05-1 | TODOに0〜100の整数で完成度を設定できること（デフォルト: 0） |
| FR-05-2 | 完成度はプログレスバーで表示されること |
| FR-05-3 | 完成度の数値（例: 75%）がプログレスバー内に表示されること |
| FR-05-4 | 完成度0〜49%: 薄い青、50〜79%: 中程度の青、80〜99%: 濃い青、100%: 最も濃い青（または緑）で表示されること |
| FR-05-5 | 完成度が100%になった時点でTODOを自動的に完了状態にするか確認ダイアログを表示すること |

### FR-06: 繰り返しタスク
| ID | 要件 |
|----|------|
| FR-06-1 | 繰り返しパターンとして「毎日・毎週（曜日指定）・毎月（日付指定）」を選択できること |
| FR-06-2 | 繰り返しの終了条件として「終了日を指定」または「回数を指定」を選択できること |
| FR-06-3 | 「今月分を生成」ボタンで、当月の未生成分を一括作成できること |
| FR-06-4 | 繰り返しタスクの編集時に「この1件のみ変更」か「以降すべてに変更」かを選択できること |
| FR-06-5 | 繰り返しタスクはグループ（recurrence_rule）で管理され、一覧から確認できること |
| FR-06-6 | 繰り返しグループを削除した場合、未来の未完了タスクを一括削除できること |

### FR-07: プロジェクト・階層管理
| ID | 要件 |
|----|------|
| FR-07-1 | プロジェクトを作成できること（タイトル・説明・目標値・開始日・期限日） |
| FR-07-2 | プロジェクトはユーザーごとに独立して管理されること |
| FR-07-3 | プロジェクト配下に子タスク（サブタスク）を追加できること |
| FR-07-4 | 子タスクはさらに子タスクを持てること（3階層以上、再帰的に無制限） |
| FR-07-5 | 各タスクノードは「進捗モード」を持つ：`percent`（完成度の平均）または `numeric`（数値目標に対する実績） |
| FR-07-6 | `numeric`モードの場合、目標値（例: 6000単語）と現在値（例: 3500）を入力できること |
| FR-07-7 | プロジェクト全体の進捗は直下サブタスクの進捗の平均で計算されること |
| FR-07-8 | 各ノードの進捗は子ノードが存在する場合、子ノードの進捗の平均を自動計算すること |
| FR-07-9 | 進捗バーに現在の進捗％と（数値モードの場合）実績値/目標値を表示すること |

### FR-08: 進捗予測・オーバー表示
| ID | 要件 |
|----|------|
| FR-08-1 | 開始日と現在の進捗から「1日あたりの進捗速度」を計算すること |
| FR-08-2 | 残り進捗と進捗速度から「完了予測日」を算出し表示すること |
| FR-08-3 | 完了予測日が期限日以内の場合、通常の青色プログレスバーを表示すること |
| FR-08-4 | 完了予測日が期限日を超える場合（遅延見込み）、プログレスバーの右端にオーバー予測分を橙色で追加表示すること |
| FR-08-5 | 今日がすでに期限日を超過している場合、超過分を赤色で表示し「+N日超過」テキストを表示すること |
| FR-08-6 | 進捗速度が0（着手していない）の場合は予測を表示せず「進捗なし」と表示すること |

### FR-09: 検索・フィルター
| ID | 要件 |
|----|------|
| FR-09-1 | タイトル・説明のキーワード検索ができること |
| FR-09-2 | 完了状態（全て/未完了/完了済み）でフィルタリングできること |
| FR-09-3 | 優先度でフィルタリングできること |
| FR-09-4 | カテゴリでフィルタリングできること |
| FR-09-5 | 締め切り日（昇順/降順）・作成日・優先度でソートできること |

---

## 非機能要件

| ID | 要件 |
|----|------|
| NFR-01 | マルチユーザー対応（Flask-Login使用） |
| NFR-02 | データはSQLiteファイルに永続化すること |
| NFR-03 | Bootstrap 5を使用したレスポンシブデザイン |
| NFR-04 | モバイルブラウザでも使いやすいこと |
| NFR-05 | Pythonは3.10以上を対象とすること |
| NFR-06 | パスワードはWerkzeugでハッシュ化して保存すること |

---

## 対象外（スコープ外）

- 外部カレンダー連携
- メール通知・リマインダー
- ファイル添付
- APIエンドポイント（REST API）
- ソーシャルログイン（Google/GitHub等）
